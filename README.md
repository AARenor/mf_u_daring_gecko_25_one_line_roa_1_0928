# One-line roast: the gadget you use every day

This is a small program that writes one short text, my entry for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: a single original line, up to 200 characters, roasting a gadget or app I use every day.

The entry text, written byte for byte with no trailing newline:

```text
My watch congratulated me on a twelve-hour stand goal I hit standing at the fridge.
```

Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` into the folder named by `MAKEFUN_OUTPUT_DIR` when set (else `/output`), creates that folder, and prints the character count to stderr.
